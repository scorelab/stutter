Stutter - Aid

Web application 

## How to Build The Stutter Web App ##
* Setup a local server: PHP+APACHE and NGIX+SQL would be required to set up the app
* Make sure that PHP and SQL are updated to the latest version
* Copy the stutter-web folder in your localhost folder
* Create a database in SQL and import the "stutter-aid.sql" into it
* Open the stutter-folder in localhost in your browser

## How to use Sutter
* After opening stutter-folder in the localhost of your browser
* View the username and password from the users table in the SQL Database and login to Stutter
